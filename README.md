# Be Aware of Lava

A little 3D pixel platformer where the floor is, quite literally, lava. Land on platforms, keep climbing, and don't let the lava touch you. Simple idea, surprisingly stressful.

Play it here: [kabirutreja.itch.io/be-aware-of-la](https://kabirutreja.itch.io/be-aware-of-la)

Made by Kabir for the PIXL YSWS program.

## Description

You control a tiny pixel guy who has to keep jumping onto new platforms while the camera slowly drifts upward and the lava rises beneath you. Fall behind and you're toast. The game is built in Unity (2D) with C#, with pixel art drawn in Piskel. The goal is simple: climb as high as you can before the lava catches you. The camera never stops moving, so hesitation is the real enemy.

**Controls**

| Action | Input |
| ------ | ----- |
| Move   | Arrow keys / WASD |
| Jump   | Space |
| Pause  | Esc |

## Getting Started

### Dependencies

* Unity (2D project). Use the editor version listed in `ProjectSettings/ProjectVersion.txt`.
* Unity Hub (recommended for opening the project)
* A desktop OS that supports Unity, e.g. Windows 10 or later, macOS, or Linux
* A keyboard

### Installing

* **Just want to play?** Open the itch.io page: [kabirutreja.itch.io/be-aware-of-la](https://kabirutreja.itch.io/be-aware-of-la)
* **Want to run the source?** Clone this repository:

```
git clone <https://github.com/kabirutreja/Dodger-Game>
cd be-aware-of-lava
```

* No file or folder changes are needed. The third-party assets listed in Credits are already included in the project (or can be re-imported from the Unity Asset Store).
